## v24 — 閱後即焚持久化
- 新增固定 key：`found-diary-burned`
- 任一分支走到結局後，會寫入：
  `localStorage.setItem("found-diary-burned", "1")`
- 同一瀏覽器、同一 GitHub Pages origin 下次重新開啟時，會直接顯示燒毀後的黑色／焦痕畫面。
- 已燒毀狀態下不再顯示日記內容與左右翻頁按鈕。
- 開發階段暫時保留「重置」按鈕。
- 重置會同時清除：
  - `found-diary-awakened-v24`
  - `found-diary-burned`
- 正式發布前再移除重置按鈕即可。
